# 14 — מילון מונחים

| מונח | משמעות מחייבת |
|---|---|
| Application | מוצר לוגי ב־Core, למשל `gotit` |
| Application User | משתמש עצמאי בתוך application אחד |
| Core | שירות משותף לזהות, sessions, billing ו־entitlements |
| Product Backend | שירות דומיין עצמאי; במקרה זה GotIt Backend |
| Learning Item | מילה/ביטוי במשמעות מסוימת ובצמד שפות |
| Sense | משמעות נפרדת של אותו source text |
| Occurrence | אירוע לכידה והקשר של item |
| Enrichment | תרגום/הסבר/פונטיקה/דוגמאות מספק |
| Selection Token | הוכחה חתומה לבחירת תוצאת provider |
| Learning Revision | גרסה סמנטית של item; משתנה בעריכת משמעות |
| Skill | recognition, recall, listening, spelling או pronunciation |
| Attempt | תשובה מדורגת סמכותית לתרגיל אחד |
| Evidence | אירוע למידה שממנו נגזרת התקדמות |
| Projection | מצב מחושב כגון mastery score או streak |
| Active Recall | הפקת source ללא רשימת אפשרויות |
| Learned | mastered ב־review stage 2–3 |
| Established | mastered ב־review stage 4 ומעלה |
| Review Stage | שלב תזמון חזרה פעילה |
| Smart Queue | דירוג שרת של items לתרגול הבא |
| Idempotency Key | UUID שמזהה פעולה retryable אחת |
| Receipt | תשובה סמכותית שמורה המוחזרת ב־replay |
| Entitlement | הרשאה עסקית ליכולת, למשל `practice.play` |
| Trial | גישה זמנית מבוססת מועד יצירת משתמש ותוכנית |
| Runtime role | DB role של שירות Web; ללא DDL |
| Migrator role | DB role זמני להרצת migrations |
| Liveness | האם התהליך חי; `/health` |
| Readiness | האם השירות יכול לקבל traffic; `/ready` |
| BCP-47 | תקן קוד שפה, למשל `en`, `he`, `zh-CN` |
| CEFR | רמות שפה A1–C2 |
| RPO | כמה נתונים מותר לאבד באסון |
| RTO | זמן יעד להחזרת השירות |
