Current implementation is isolated on `feat/free-learning-path-dev-20261021`; production and the dirty primary worktrees are not release sources. ## Behavior

All enrolled structured-program units, authored teacher lessons, word activities, phonics, unit reading and assessments can be selected directly. Legacy prepared teacher stations are also selectable before their recommended word/preparation thresholds. Personal courses accept an explicit active-version/unit/lesson selection. Choosing content does not implicitly skip earlier work or alter learning evidence. The default continuation selects unfinished, unskipped content in the recommended path; due review remains recommended independently.

Learners can skip or restore a single map stage or the unfinished remainder of a unit. Unit skipping has an explicit confirmation showing the unfinished count. Completed work and saved attempts, drafts, reports and homework remain accessible. Skipped and completed stages have distinct labels and counts. Reaching the end of a chosen route is not described as mastering all omitted content. Restoration never deletes later evidence or relocks access.

Postlesson practice retains its actual teacher-source dependency. Skipping an unfinished meeting also omits its unavailable dependent practice from recommendations; restoring the meeting makes its preparation relevant again. This dependency is explained in the map. Generated readings retain target/time eligibility and provider limits; enrollment, authentication, billing entitlements, provider availability and voice-minute reservations are not navigation locks and remain enforced.

Skips create no attempts, grades, word familiarity/mastery, SRS changes, XP, streak activity, placement or CEFR evidence. Structured graduation still requires real unit/unseen evidence or the existing demonstrated placement waivers, plus independent exit evidence in all four skills. Accessing an assessment early does not waive these completion conditions. Existing task-level homework ordering and private answer disclosure are unchanged.

## Authority, persistence and API

- `POST /api/v1/structured-english/path-choices`: `{eventId, revision, unitId, activityId?, skipped}`. Uses existing enrollment revision/advisory locking and stored-command replay. Choices are stored separately in the version-scoped enrollment JSON as `pathChoices: {units, activities}`. Invalid unit/activity combinations, foreign scope, stale revisions and changed-payload replays reject. GET adds safe choices, per-unit skipped flags and `navigationComplete`; unit detail adds safe path-step states.
- `POST /api/v1/courses/:id/path-choices`: `{eventId, revision, version, unitKey, lessonIndex?, skipped}`. Omitting `lessonIndex` changes the unfinished unit remainder. Choices use existing course commands and revision concurrency. They are compatible only with the same active unit content; changed unit content does not inherit old skips. Public course responses add `skippedLessons` separately from filtered learning evidence.
- Existing `POST /api/v1/private-lessons/realtime-sessions` accepts additive `courseLesson: {version, unitKey, lessonIndex}` only with `courseId`. The server resolves the exact active lesson before provider/minute allocation. Omission preserves the normal next-lesson flow. Stale/invalid selections reject instead of silently starting another lesson.
- `POST /api/v1/private-lessons/units/:id/path-choices`: `{eventId, revision, step?, skipped}`. Initial virtual navigation revision is `-1`; existing learning-document receipt/revision storage serializes writes. Nine canonical keys use `supported|midpoint|review` plus `words|meeting|homework`. Actual completion wins over skip labels. The returned map is a current read after the idempotent mutation. Catalog `progress.pathSkipped` is separate from `unitCompleted`.

Migration `1792620000000_learning-path-choices.js` expands the existing `learning_documents.kind` constraint with `unit_path` and adds a partial owner/pack index. It creates no new table or privilege. Navigation documents use deterministic IDs in a separate namespace and existing scoped FKs/receipts. Existing course/homework reads remain kind-filtered. Down refuses to remove the constraint while navigation documents exist; application rollback should retain the additive schema and learner choices.

Web accepts old responses without the additive choice fields. Existing requests remain valid. Core and Chrome do not consume the new path commands and require no source or deployment change. Eight locales, native keyboard controls, confirmation focus management and a narrow-screen stacked action layout cover the new interaction. No external analytics or provider data is added by skipping.
